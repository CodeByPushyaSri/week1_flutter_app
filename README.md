# Week 1 Flutter Internship Project

## Project Overview

This project is a basic Flutter application developed for the Week 1 Flutter Frontend Development Internship task. It demonstrates screen design, navigation, forms, and basic user interactions.

## Screens

1. **Splash Screen** — Introduction screen with a Get Started button.
2. **Login Screen** — Email and password fields with basic form validation.
3. **Home Screen** — Welcome message and navigation to Profile and Settings.
4. **Profile Screen** — Displays sample user information.
5. **Edit Profile Screen** — Allows editing sample name and email fields.
6. **Settings Screen** — Contains a notification preference switch.

## Technologies

* Flutter
* Dart
* Material Design widgets

## Project Structure

* `lib/main.dart` — Contains the application entry point, UI screens, and navigation.
* `pubspec.yaml` — Contains project metadata and dependencies.
* `android/`, `web/`, and other platform folders — Platform-specific project files generated by Flutter.

## How to Run

1. Install Flutter and configure the development environment.
2. Open a terminal in the project root.
3. Run `flutter pub get`.
4. Run `flutter run -d chrome`.

## Limitations

This is a front-end demonstration. Login is not connected to a real authentication service, and profile changes are not permanently stored.
